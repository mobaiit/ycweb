选这门语言的时候，我没有想太多。

那是大一下学期，学校的课程表上写着"Java 程序设计"，室友们在宿舍里讨论要不要逃课去打游戏。我没怎么参与讨论，只是把课本翻开，从第一页开始看。不是因为多热爱，只是觉得：既然要学，就认真学。

但真正把 Java 选定为主力语言，是后来的事。

## 那些骂 Java 的声音

大学里的技术圈子有个默认鄙视链。

Python 最酷，"两行代码能做什么"是标准的炫技方式。JavaScript 全栈，"一门语言走天下"是口号。C++ 是硬核，底层玩家的标配。Java 呢——"那是大厂给 CRUD boy 准备的工具"，或者"企业级别的古董，学了能找到工作但没什么品位"。

我听过很多次这类评价。开始会有点动摇，后来就彻底不在意了。

因为我发现，说这些话的人，大多数连 Java 的内存模型是怎么回事都没深入研究过，更别说 JVM 调优、并发编程、Spring 那套生态的设计逻辑。他们的鄙视是廉价的，建立在没有真正深入过的基础上。

## 啰嗦是一种诚实

Java 有一个特质，很多人把它当缺点：啰嗦。

声明一个字符串列表，要写 `List<String> list = new ArrayList<>()`。声明一个方法，要写访问修饰符、返回类型、方法名、参数列表。一个简单的数据类，如果不用 Lombok，需要手写 getter、setter、constructor、toString、equals、hashCode。

Python 用三行能做的事，Java 可能要二十行。

但我后来慢慢觉得，这种啰嗦不是多余的，它是一种强迫机制——强迫你把每一个细节都想清楚，写明白。`List<String>` 告诉所有读代码的人：这是字符串，不是整数，不是对象。访问修饰符告诉人：这个方法是公开的还是私有的，谁能调用，谁不能。

**一门语言的啰嗦，某种程度上是它的诚实。** 它不允许你含糊，不允许你"先写着，反正能跑"。

我见过太多"简洁"的动态语言代码在生产环境里崩溃，然后没有人知道某个变量到底是字符串还是整数，到底会不会是 null，到底这个方法在什么情况下会抛出什么异常。Java 的啰嗦在这种场景下是救命稻草。

## 深不见底的生态

真正让我确认选择 Java 的，是某个春节，把 Spring 官方文档从头到尾啃了一遍。

那是疫情刚开始的春节，大家都闷在家里。我坐在台灯下，窗外偶尔传来外卖电动车的声音，屋里很安静。打开浏览器，进入 docs.spring.io，从 Spring Framework 的 Introduction 开始看。

依赖注入的设计思想让我看了很久。不是语法多难，而是这个概念背后的工程哲学：把对象的创建和依赖关系的管理交给容器，业务代码只关心业务逻辑，不关心怎么拿到依赖。这是一种真正的解耦。

AOP 更让我着迷。面向切面——把横切关注点（日志、事务、权限）从业务逻辑里剥离出来，单独处理。这不是在发明新东西，而是在用优雅的方式解决真实存在的工程问题。

事务管理、缓存抽象、消息驱动……每展开一层，就发现下面还有更深的东西。Spring 生态的深度不是靠堆砌功能堆出来的，而是在解决一个又一个真实问题的过程中自然生长出来的。

**我喜欢有历史厚度的东西。** Java 跑了将近三十年，Spring 也二十年了。不是因为它们没有被替代，而是因为它们确实在做正确的事。存活本身就是一种证明。

## 第一个真正的项目

大二下，选修了一门 Web 开发课，要求用 Java 做一个学生信息管理系统。

我用了 Servlet + JSP，部署在老师提供的一台 Linux 服务器上，连接 MySQL。第一次让一个真实的网页跑起来，而不是在本地 console 打印 Hello World。

那个系统现在回头看简直惨不忍睹——没有输入校验，SQL 是直接字符串拼接（后来才知道这叫 SQL 注入），异常处理全靠 `e.printStackTrace()`，没有任何事务管理，登录功能用的是明文密码对比。

但它能跑。浏览器输入地址，页面出来，数据在数据库里，增删改查全通。

那个晚上，我把作业提交之后，看着终端里 Tomcat 的启动日志，有一种很踏实的满足感。不是因为做了多了不起的东西，而是因为那一刻感受到了：代码可以变成真实的东西，可以被人使用，可以改变什么。

那种感觉，是我后来无论多累都没有彻底放弃这条路的原因之一。

---

现在已经过了好几年。Java 的版本从 8 到 17 到 21，Spring Boot 也出到了 3.x，Kotlin 在 JVM 生态里越来越活跃，虚拟线程让 Java 的并发模型更接近 Go 的协程。

这门语言一直在变，一直在回应时代的需求。

我也一直在变，一直在这条路上往更深处走。

有些选择，不是因为最开始想清楚了才选，而是在走的过程中，慢慢发现自己走对了。

像春节那个夜晚，台灯下翻着文档，窗外安静，不知不觉已经看到了凌晨两点。
