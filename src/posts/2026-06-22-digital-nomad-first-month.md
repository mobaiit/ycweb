## 决定离开

五月初，我发了最后一封离职邮件。

没有煽情的告别，没有"感谢公司培养"的客套话。邮件只有三句：

> 即日起离职。  
> 交接文档已上传至 Confluence。  
> 运行。

HR 打电话过来，问我是不是有什么不满。

**我只是想要绝对的自由。**

不想在固定的时间、固定的地点，做可以在任何地方完成的工作。不想把生命浪费在通勤、会议、和假装在工作的下午茶上。

我攒了两年的钱，买了一张单程机票，飞往冰岛。

## 冰岛的第一周

雷克雅未克比我想象中更冷、更安静。

Airbnb 在市区边缘，落地窗对着远处的雪山。桌上只有一台笔记本、一杯冷萃黑咖啡、和一盏护眼灯。

**这就是我需要的全部。**

第一周主要在倒时差和熟悉环境。白天出去走走，看火山遗迹和黑沙滩；晚上回来继续写代码。

没有人催进度，没有无意义的日报周报，只有我和键盘的对话。

## 远程工作的节奏

做数字游民不是度假，而是换了个地方工作。

我接了一个 AI Agent 的外包项目，用 Python + LangChain 搭建智能客服系统。客户在国内，但所有沟通都在 Slack 上，异步协作完全没问题。

**我的作息：**

- 凌晨 2:00 - 6:00：深度工作时间，写核心逻辑
- 上午：睡觉
- 下午 3:00 - 5:00：回复邮件，处理琐事
- 晚上：出去走走，或者继续写代码

没有人规定我必须 9 点打卡、6 点下班。**时间是我的，我说了算。**

## 技术栈的演进

做远程项目后，我开始更关注工具链的效率。

### 云端开发环境

笔记本只有 16GB 内存，跑不了完整的 K8s 集群。所以我把开发环境全部迁移到云端：

- **代码托管**：GitHub + Codespaces
- **容器编排**：AWS EKS
- **数据库**：RDS + ElastiCache
- **监控**：Datadog

本地只需要一个终端 + VSCode，剩下的全在云上。哪怕笔记本丢了，换台电脑登录账号就能继续工作。

### 自动化部署

远程工作最怕的是环境问题。所以我花了两天搭建了完整的 CI/CD 流程：

```yaml
git push → GitHub Actions → Docker Build → K8s Deploy → Slack 通知
```

代码提交后，5 分钟自动部署到生产环境。我可以在海边散步时，用手机看部署日志。

## 孤独与自由

有人问我："一个人在异国他乡，不孤独吗？"

**孤独和独处是两回事。**

我享受独处，因为这是我效率最高的状态。没有人打扰，没有无意义的社交，只有纯粹的思考和创造。

但我也不是完全与世隔绝。偶尔会在咖啡馆遇到其他数字游民，聊聊技术和旅行。聊得来就多说几句，聊不来就点头离开。

**我不需要很多朋友，但我珍惜每一个真正懂我的人。**

## 成本与收入

很多人觉得数字游民是有钱人的游戏。其实不是。

### 支出

- **住宿**：$800/月（Airbnb 月租优惠）
- **饮食**：$400/月（自己做饭为主）
- **交通**：$100/月（偶尔租车）
- **网络**：$50/月（4G 无限流量卡）

**总计：$1350/月**

比在国内一线城市租房还便宜。

### 收入

远程外包项目，按项目结算。一个月接 1-2 个项目，收入 $3000-5000。

**够花，而且有余。**

## 教训

### 1. 网络是生命线

第一周遇到 Airbnb 的 WiFi 故障，差点误了项目 deadline。

**解决**：买了本地 4G 无限流量卡，随身带着移动热点。永远有 Plan B。

### 2. 时差需要适应

客户在北京，时差 8 小时。刚开始经常半夜被叫起来开会。

**解决**：和客户约定固定沟通时间（他们下午 3 点 = 我早上 7 点），其他时间异步沟通。

### 3. 孤独是双刃剑

自由的代价是失去了公司的安全感。没有固定工资，没有五险一金，一切靠自己。

**但我不后悔。** 这种不确定性正是我想要的。
